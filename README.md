# Prof. Dr. Adnan Kaya

İzmir Katip Çelebi Üniversitesi, Elektrik-Elektronik Mühendisliği

Elektromanyetik dalgalar, antenler ve **PEMF (darbeli elektromanyetik alan)** teknolojileri üzerine çalışıyorum: bobin tasarımı, sinyal üretimi, gömülü sistemler ve biyomedikal uygulamalar.

### Çalışma alanları

- PEMF bobin ve sürücü tasarımı (toroid, Rodin, Helmholtz, planar)
- Gömülü sistemler (ESP32), Web Bluetooth kontrol uygulamaları (PWA)
- Mikrodalga mühendisliği, antenler, akıllı sensörler, RFID
- Elektromanyetikte sayısal yöntemler (Biot-Savart, CST, openEMS)
